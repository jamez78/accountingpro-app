## ✨ What's inside

- **Full accounting** — General Ledger, AP, AR, journal entries, bank reconciliation, trial balance, financial reports
- **Philippine payroll** — SSS, PhilHealth, Pag-IBIG, and BIR withholding tax auto-computed, with an approval workflow
- **Procurement** — Purchase Requisition → PO → Goods Receipt → Invoice Verification → Payment
- **HR & 201 File** — employee records, leave, attendance
- **37 modules · 16 business types** — a setup wizard configures your chart of accounts and modules automatically
- **Standalone & offline** — installs as a Windows app; no internet required
- **LAN multi-user** — one PC runs it; others connect by browser on the office network
- **Role-based security** — Admin, Accounting, HR, Sales, Purchasing

## 🖥️ Install

1. Download the installer from the latest release.
2. Run it. Windows SmartScreen may warn (the app is unsigned) — click **More info → Run anyway**.
3. Launch **AccountingPro ERP** from the Desktop / Start menu.
4. First launch shows a quick **Setup Wizard** (company + business type). Default login afterwards: `admin` / `Admin@123` — please change it.

**Requirements:** Windows 10/11 (64-bit). No other software needed.
